## Directory Contents
- `CPU.hdl`: Complete Hack CPU hardware implementation.
- `Memory.hdl`: Hack Memory chip routing RAM16K, Screen, and Keyboard.
- `Computer.hdl`: Top-level Hack Computer chip connecting CPU, Memory, and ROM32K.
- `assembler.py`: Python assembler with two-pass symbol resolution and duplicate label warning feature (K mod 3 = 2).
- `Box.asm`: Hack assembly program drawing 48x20 pixel black box at Row 38 on keypress, clearing on release.
- `Box.hack`: Assembled binary machine code generated by `assembler.py`.
- `symbols.txt`: Exported symbol table.
- `REPORT.md`: Comprehensive 3-4 page short report ready for submission on ZOSIMA.
- `VIVA_PREP.md`: Rapid-fire viva questions and explanations of on-the-spot code changes.
- `screenshot_box.png`: Verified visual output screenshot of CPU Emulator.

## How to Run the Assembler
To assemble `Box.asm` into `Box.hack`:
```bash
python assembler.py Box.asm
```

To test on other programs:
```bash
python assembler.py Add.asm
python assembler.py Max.asm
```

---

## How to Run in CPU Emulator
1. Open the Nand to Tetris `CPUEmulator.bat`.
2. Load Program: select `Box.hack`.
3. Set Animation to `Program & Data` or `No display` (Fast).
4. Click `Run`.
5. Focus the emulator and hold down any keyboard key -> solid black box appears at Row 38.
6. Release the key -> the box clears immediately back to white.
