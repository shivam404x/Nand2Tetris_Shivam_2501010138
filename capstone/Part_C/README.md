## Overview
Part C implements `Box.asm`, an interactive Hack assembly program that continuously monitors keyboard input (`RAM[24576] / KBD`).
- When **any key is pressed** (\(\text{KBD} \neq 0\)), a solid black rectangle appears on the screen.
- When the **key is released** (\(\text{KBD} = 0\)), the box disappears immediately.

---

## Box Dimensions for K = 38
- **Vertical Origin (Row):** Row \(K = \mathbf{38}\)
- **Start Address in Screen Memory:** \(\text{SCREEN} + 32 \times 38 = 16384 + 1216 = \mathbf{17600}\)
- **Box Height:** **20 rows** (Rows 38 to 57 inclusive)
- **Box Width:** \(16 \times ((38 \pmod 4) + 1) = 16 \times 3 = \mathbf{48\text{ pixels}}\) (Words 0, 1, 2 from the left edge)

## How to Run & Test
1. **Interactive Browser Emulator:**
   ```powershell
   start emulator.html
   ```

2. **Terminal Simulator:**
   ```powershell
   python run_test.py
   ```

3. **Re-assemble with your own Assembler:**
